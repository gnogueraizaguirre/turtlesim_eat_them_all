# turtlesim Eat Them All

This is a personal project to test myself in the basics of ROS 2. It'll be based on Turtlesim. 

The idea is to have turtlesim with a bunch of randomly spawning turtles and another turtle (my_turtle) that will navigate towards them, eat them (despawn them) and move on to the next closest turtle, without hitting the map edge.

This is based on the final project in ROS 2 for Beginners.
